# Сбор и анализ учебного расписания ТвГТУ: мессенджер MAX и прямой шлюз вуза

Репозиторий содержит законченное исследование двух независимых способов получения, обработки и выгрузки расписания занятий Тверского государственного технического университета (ТвГТУ):
1. **Вариант 1 (`1_max_messenger_parser`)**: работа через клиентский контур мессенджера MAX (`web.max.ru` / `@vuz_schedule_bot` / `schedule.vk-apps.com`).
2. **Вариант 2 (`2_tstu_api_direct`)**: прямое взаимодействие с открытым веб-шлюзом ТвГТУ (`new.tstu.tver.ru/api/tver_polytech_bot/`).

Оба варианта поддерживают:
- Выбор **любой академической группы университета**, включая магистратуру (`М.`), бакалавриат (`Б.`), специалитет (`С.`), колледж СПО (`СПО.`) и аспирантуру (`А.`);
- Сквозной поиск расписания **преподавателей всех факультетов** (ФИТ, ХТФ, МСФ, ИСФ, ФУСК) с выгрузкой в JSON и Excel;
- Удобные графические веб-интерфейсы и консольные команды для автоматизации;
- Изолированное хранение сформированных отчетов в каталогах `output/groups/` и `output/teachers/` без захламления корня проекта.

## 1. Сравнительный анализ подходов

| Параметр | Вариант 1: Мессенджер MAX | Вариант 2: Прямой веб-шлюз ТвГТУ |
| :--- | :--- | :--- |
| **Сетевой ресурс** | `https://schedule.vk-apps.com/v1/` | `https://new.tstu.tver.ru/api/tver_polytech_bot/` |
| **Аутентификация** | Требуется (`WebAppData`, HMAC-SHA256, JWT) | Не требуется (свободный доступ к справочнику) |
| **Срок жизни ключей** | `auth_token`: 600 с (10 мин), `refresh_token`: 12 ч | Бессрочно |
| **Охват групп** | 463 группы (бакалавриат, магистратура, СПО и др.) | 438 групп в реестре шлюза |
| **Выходные форматы** | Стилизованный Excel (`.xlsx`), JSON | Стилизованный Excel (`.xlsx`, `.xls`), JSON |
| **Пользовательский интерфейс** | Локальный Web UI (`http://127.0.0.1:8080`) | Автономный HTML-просмотрщик (`web_viewer.html`) |

## 2. Руководство для пользователя: как получить ключ из мессенджера MAX

Если пользователь не знает, где брать ключ или токен доступа для мессенджера MAX, предусмотрен сценарий автоматического обмена. Ручной ввод токенов не требуется: достаточно скопировать ссылку мини-приложения из браузера.

### Пошаговая инструкция:
1. Откройте веб-версию мессенджера MAX в браузере: [`web.max.ru`](https://web.max.ru).
2. Перейдите в чат с ботом `@vuz_schedule_bot` и нажмите кнопку открытия расписания («Открыть расписание»).
3. Нажмите клавишу **F12** (или `Ctrl + Shift + I`) для вызова панели разработчика браузера и перейдите на вкладку **Console** (Консоль).
4. Вставьте следующую команду и нажмите **Enter**:
   ```javascript
   copy(document.querySelector('iframe[src*="schedule"]').src)
   ```
   *Ссылка на фрейм с параметрами `WebAppData` скопируется в буфер обмена автоматически.*
5. Перейдите в веб-интерфейс Варианта 1 (`http://127.0.0.1:8080`) и вставьте скопированную ссылку в поле «Ссылка фрейма или WebAppData», затем нажмите кнопку **«Получить токены и расписание»**.
   - Система автоматически извлечет подпись HMAC-SHA256;
   - Выполнит сетевой запрос к `POST https://schedule.vk-apps.com/v1/auth`;
   - Получит рабочие `auth_token` и `refresh_token`, сохранив сессию в `data/session_credentials.json`;
   - Сразу загрузит расписание выбранной группы.

Эту же ссылку можно передать через консоль:
```bash
cd 1_max_messenger_parser
python main.py --login "вставить_скопированную_ссылку"
```

## 3. Выбор учебной группы (включая магистратуру и колледж)

В обоих вариантах обеспечен выбор любой из 400+ групп университета:

### 3.1. В Варианте 1 (`1_max_messenger_parser`):
- **Просмотр групп с фильтром:**
  ```bash
  # Список групп магистратуры (75 групп)
  python main.py --list-groups магистратура
  python main.py --list-groups М.

  # Список групп бакалавриата
  python main.py --list-groups Б.ПИН
  ```
- **Интерактивный выбор в терминале:**
  ```bash
  python main.py --select-group
  ```
- **Фиксация группы для синхронизации:**
  ```bash
  python main.py --group М.ПИН.РИС.25.09
  python main.py --group Б.ПИН.ИИ.25.16
  ```
- **В веб-панели (`http://127.0.0.1:8080`):**
  В блоке «Выбор учебной группы» доступны вкладки «Магистратура (М.)», «Бакалавриат (Б.)», «Специалитет (С.)», «Колледж (СПО)», поле поиска с автодополнением и быстрые чипы.

### 3.2. В Варианте 2 (`2_tstu_api_direct`):
- **Просмотр групп с фильтром:**
  ```bash
  # Фильтр по магистратуре
  python main.py --list-groups магистратура

  # Фильтр по колледжу или специалитету
  python main.py --list-groups СПО.
  python main.py --list-groups С.РСК
  ```
- **Выгрузка расписания конкретной группы:**
  ```bash
  # Магистратура
  python main.py --group М.ПИН.РИС.25.09

  # Бакалавриат
  python main.py --group Б.ПИН.ИИ.25.16
  ```
- **В просмотрщике `web_viewer.html`:**
  Интерактивные вкладки ступеней образования, автодополнение по 438 группам и динамическое перестроение сетки учебных занятий.

## 4. Сквозной поиск и выгрузка расписания преподавателей

### Причина пустых файлов ранее:
Ранее при выгрузке расписания преподавателей других кафедр (например, профессора Лебедева В.В. с кафедры биотехнологии и химии ХТФ) создавался пустой массив `[]` (файл размером 2 байта). Это происходило из-за жесткой привязки поиска только к четырем группам факультета информационных технологий (ФИТ).

### Реализованное решение:
1. Создан общий реестр научно-педагогического состава `teachers_directory.json` (60+ преподавателей университета по всем факультетам: ХТФ, ФИТ, МСФ, ИСФ, ФУСК).
2. При указании преподавателя система определяет его кафедру и опрашивает профильные группы соответствующего факультета:
   - Для профессора Лебедева В.В. опрашиваются группы химико-технологического факультета (`Б.БТ.ПБ.25.14`, `М.БТ.ПБ.26.14`);
   - Для преподавателей ФИТ опрашиваются группы программистов и системных аналитиков.
3. По результатам формируются полные файлы `Преподаватель_<ФИО>.json` и стилизованный отчёт Excel (например, 5 занятий профессора Лебедева В.В. корректно сформированы и сохранены).

### Запуск выгрузки по преподавателю:
```bash
# Вариант 1 (MAX):
cd 1_max_messenger_parser
python main.py --teacher Лебедев

# Вариант 2 (Прямой шлюз):
cd 2_tstu_api_direct
python main.py --teacher Лебедев
python main.py --teacher Пиджакова
```
