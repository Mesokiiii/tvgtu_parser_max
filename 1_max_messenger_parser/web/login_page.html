Как выгрузить расписание из МАКС в 3 простых шага

В мессенджере МАКС расписание работает внутри мини-приложения. Чтобы скрипт мог выгружать актуальные данные, передайте ему рабочую ссылку или параметры сессии:

Шаг 1
Открыть бота

Перейдите в чат с официальным ботом расписания и нажмите кнопку «Открыть».

@vuz_schedule_bot
Шаг 2
Скопировать ссылку

Нажмите F12 в браузере → вкладка Console → вставьте команду и нажмите Enter:

copy(document.querySelector('iframe[src*="schedule"]').src)
Шаг 3
Подключить сессию

Вставьте скопированное значение ниже или нажмите кнопку автоматической вставки:

Альтернативные варианты извлечения ссылки:
  • Через вкладку Elements: Нажмите F12 → Ctrl+F → введите digital-uni-schedule → скопируйте атрибут src="..." у найденного тега <iframe>.
  • Через вкладку Network: Нажмите F12 → вкладка Network → фильтр schedule → кликните правой кнопкой мыши по запросу schedules или auth → Copy → Copy as cURL → вставьте сюда.
