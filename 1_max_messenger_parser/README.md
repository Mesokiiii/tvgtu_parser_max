# Модуль интеграции с API мини-приложения мессенджера MAX

Модуль предназначен для взаимодействия с программным интерфейсом цифрового расписания (сервер schedule.vk-apps.com), функционирующего в составе мессенджера MAX (web.max.ru). Поддерживает выбор любых академических групп ТвГТУ (бакалавриат, магистратура, специалитет, колледж) и выгрузку расписания преподавателей.

## 1. Где взять ключ и как выгрузить расписание из МАКС (Руководство пользователя)

В мессенджере МАКС расписание работает внутри контейнера `<iframe>`. Пользователю не нужно вручную декодировать криптографические ключи — достаточно передать ссылку или параметры мини-приложения:

### Способ 1. Автоматическое копирование через консоль браузера (1 клик)
1. Откройте мессенджер [web.max.ru](https://web.max.ru) и войдите в чат с ботом `@vuz_schedule_bot` (кнопка «Открыть расписание»).
2. Нажмите клавишу <kbd>F12</kbd> (или сочетание <kbd>Ctrl+Shift+I</kbd>), перейдите на вкладку **Console**.
3. Вставьте одну строку и нажмите <kbd>Enter</kbd>:
   ```javascript
   copy(document.querySelector('iframe[src*="schedule"]').src)
   ```
4. Ссылка на мини-приложение скопирована в буфер обмена.
5. Откройте панель управления [http://localhost:8080](http://localhost:8080) и нажмите кнопку **«Вставить из буфера и войти»**. Сервер автоматически произведет обмен на пару рабочих токенов (`auth_token` и `refresh_token`), обеспечив 12 часов автономной работы.

### Способ 2. Копирование через вкладку Elements (DevTools)
1. В окне мессенджера с открытым расписанием нажмите <kbd>F12</kbd>.
2. Нажмите <kbd>Ctrl+F</kbd> и введите `digital-uni-schedule`.
3. В теге `<iframe src="...">` дважды кликните по значению атрибута `src` и скопируйте его (<kbd>Ctrl+C</kbd>).
4. Вставьте ссылку в веб-панель управления.

### Способ 3. Копирование cURL через вкладку Network
1. В <kbd>F12</kbd> откройте вкладку **Network** и введите в поле фильтра `schedule`.
2. Кликните правой кнопкой мыши по запросу `schedules` или `auth` &rarr; выберите пункт **Copy &rarr; Copy as cURL**.
3. Вставьте скопированный текст cURL в веб-панель: токен `Bearer eyJ...` будет извлечен автоматически.

## 2. Выбор академических групп (включая магистратуру)

Модуль содержит каталог из 463 учебных групп университета.

### Уровни подготовки:
- **Бакалавриат (`Б.`)**: 256 групп (например, `Б.ПИН.ИИ.25.16`, `Б.ИВТ.ВМКСС.25.03`).
- **Магистратура (`М.`)**: 75 групп (например, `М.ПИН.РИС.25.09`, `М.ИВТ.ИПО.25.05`, `М.БСТ.ИДМ.25.10`, `М.БТ.ПБ.26.14`).
- **Специалитет (`С.`)**: 33 группы (например, `С.РСК.РСК.24.05`, `С.ГД.ОГР.21.02`).
- **Колледж (`СПО.`)**: 5 групп колледжа ТвГТУ.

### Команды консоли для выбора групп:
Просмотр списка магистерских групп:
```bash
python main.py --list-groups магистратура
```

Установка целевой группы (включая магистратуру) и выгрузка расписания:
```bash
python main.py --group М.ПИН.РИС.25.09 --fetch
```

Интерактивный мастер выбора группы в терминале:
```bash
python main.py --select-group
```

Поиск расписания преподавателя (с автоматическим определением кафедры и профильных групп):
```bash
python main.py --teacher Лебедев
```

## 3. Архитектура решения

```text
1_max_messenger_parser/
├── core/                      # Доменные сервисы
│   ├── session_manager.py     # SessionManager: хранение токенов, каталог 463 групп, парсинг WebAppData
│   ├── auth_client.py         # MaxAuthClient: первичный обмен /v1/auth и refresh /v1/auth/refresh
│   └── schedule_client.py     # MaxScheduleClient: сквозная загрузка расписания групп и преподавателей
├── exporters/                 # Генераторы отчетов
│   ├── excel_exporter.py      # MaxExcelExporter: экспорт в Excel (.xlsx) с подсветкой недель
│   └── json_exporter.py       # MaxJsonExporter: сохранение в формат JSON
├── web/                       # Веб-панель управления
│   ├── http_server.py         # WebControlServer: локальный HTTP сервер и REST API
│   ├── login_page.html        # Интерфейс 3-шагового мастера, селектора групп и преподавателей
│   ├── app.js                 # Клиентская логика веб-панели
│   └── style.css              # Оформление в стиле Altitude
├── data/                      # Данные и справочники
│   ├── tokens.json            # Актуальные токены сессии и целевая группа
│   ├── tvgtu_groups.json      # Каталог академических групп ТвГТУ
│   └── teachers_directory.json# Каталог преподавательского состава кафедр
├── output/                    # Каталог сформированных отчетов
│   ├── groups/                # Расписания учебных групп (.json, .xlsx)
│   └── teachers/              # Расписания преподавателей (.json, .xlsx)
└── main.py                    # Консольная точка входа
```

Запуск веб-панели:
```bash
python main.py
```
После старта веб-интерфейс доступен по адресу `http://localhost:8080`.
